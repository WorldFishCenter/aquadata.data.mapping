# Read uploaded file

This function read uplaoded file from the user. It returns a object
based on the extension of the file. Allowed formats are docx, pdf, txt.

## Usage

``` r
read_file(file = NULL)
```

## Arguments

- file:

  The uploaded file.

## Value

A text.

## Examples

``` r
if (FALSE) { # \dontrun{
read_text("my_file.pdf")
} # }
```
