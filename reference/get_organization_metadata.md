# Download metadata

This function is a wrapper of a python script
\`get_dataverse_metadata.py\` udeful to download metadata from a defined
Dataverse.

## Usage

``` r
get_organization_metadata(organization = NULL)
```

## Arguments

- organization:

  The Dataverse alias of the entity posting the data.

## Value

A csv with metadata information.

## Examples

``` r
if (FALSE) { # \dontrun{
get_organization_metadata(organization = "CIAT")
} # }
```
