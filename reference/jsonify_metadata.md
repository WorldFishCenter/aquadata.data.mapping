# Rearrange metadata for apexcharter

This function is strictly related to \`apexcharter\`, as it rearrange
the metadata dataframe in the shape of "list of lists" in order to be
correctly processed by \`apex_treemap\` function.

## Usage

``` r
jsonify_metadata()
```

## Value

A list.

## Examples

``` r
if (FALSE) { # \dontrun{
metadata_lists <- jsonify_metadata()
} # }
```
